# Python Lab Experiments

## About
This repository contains Python programs developed as part of laboratory practice to strengthen programming fundamentals, logical thinking, and problem-solving skills. It includes mathematical computations, number-based programs, pattern printing, and basic algorithmic exercises.

## Programs Covered

- **Number Programs:** Armstrong Number, Factors of a Number, LCM, and GCD
- **Mathematical Operations:** Factorial and Fibonacci Series
- **Pattern Printing:** Diamond, Hollow Rectangle, Inverted Pyramid, and Inverted Right-Angle Triangle
- **Array/List Operations:** Finding the nth maximum and nth minimum elements
- **Additional Exercises:** Leap Year Checking and other fundamental programming problems

## Technologies Used
- **Programming Language:** Python 3
- **Tools:** Visual Studio Code, IDLE, or any Python-compatible IDE
- **Version Control:** Git and GitHub

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/juhisakshisurin/CSA0829.git
   ```

2. Navigate to the repository folder:

   ```bash
   cd CSA0829
   ```

3. Run a Python program:

   ```bash
   python FACTORIAL.py
   ```

   If required, use `python3` instead of `python`.

Replace `FACTORIAL.py` with the filename of the program you want to execute.

## Learning Objectives
- Understand Python syntax and programming fundamentals.
- Develop logical thinking through mathematical problems.
- Implement loops, conditionals, and functions.
- Practise number-based algorithms and pattern generation.
- Improve problem-solving and coding skills.

## Repository Structure
Each `.py` file contains an individual Python program designed to demonstrate a specific programming concept or solve a particular problem.
